# BLACK FIT

BLACK FIT은 순수 HTML, CSS, JavaScript로 제작한 패션 커머스 포트폴리오 웹사이트입니다. 미니멀한 블랙/화이트 기반의 패션 플랫폼 무드로 메인 페이지, 상품 리스트, 상품 상세, 장바구니, 로그인, 관리자 관리 흐름을 구현했습니다.

## 주요 기능

- 반응형 메인 페이지, 룩북, 브랜드, 이벤트, 검색, 마이페이지, 고객지원 서브페이지
- JavaScript 배열 기반 상품 데이터 렌더링
- 카테고리, BEST/NEW, 가격대, 검색, 정렬 필터
- 상품 상세 모달, 사이즈/수량 선택, 리뷰 탭, 상품 스펙 정보
- localStorage 기반 장바구니, 찜, 최근 본 상품, 최근 검색어, 주문 내역 저장
- 로그인/로그아웃 및 관리자 상품/주문 관리
- 모바일 하단 탭바, 모바일 메뉴, 장바구니 사이드 패널
- favicon, iOS/Android 홈화면 아이콘, Web App Manifest 적용

## 사용 기술

- HTML5
- CSS3
- Vanilla JavaScript
- localStorage

## 배포

별도 빌드 과정이 없는 정적 웹사이트입니다. Vercel에서 Framework Preset을 `Other`로 선택하고 기본 설정 그대로 배포하면 됩니다.
